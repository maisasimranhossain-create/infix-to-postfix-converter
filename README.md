# Infix to Postfix Converter

## Overview
A C-based program that converts mathematical expressions from infix notation to postfix notation using the Stack data structure.

## Objective
To understand how stacks and operator precedence are used in expression conversion.

## Concepts Used
- C Programming
- Stack (LIFO)
- Arrays
- Functions
- Operator Precedence
- Expression Conversion

## Example

**Input:**
```text
A+B*C
```

**Output:**
```text
ABC*+
```

## Operators Supported
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Exponentiation (^)

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)

## Future Improvements
- Multi-digit operand support
- Postfix expression evaluation
- Improved expression validation
